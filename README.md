# NeuroSense 🧠

NeuroSense is an AI-powered cognitive assessment and dementia prediction platform developed to assist in the early identification of neurological disorders through interactive testing, intelligent analysis, and performance monitoring.

The project focuses on providing a simple, accessible, and efficient system that can evaluate cognitive behavior using modern web technologies and AI-based processing techniques.

---

# Features

## Cognitive Assessment Tests
Interactive tests designed to evaluate memory, attention, concentration, and cognitive response patterns.

## AI-Based Analysis
Processes user test results and generates intelligent evaluations for identifying possible cognitive decline indicators.

## User Authentication
Secure login and registration system for managing user accounts and protecting assessment data.

## Dashboard and Reports
Displays user performance, assessment history, and analytical results in an organized interface.

## Responsive Design
Fully responsive user interface that works across desktops, tablets, and mobile devices.

# Installation and Setup

Clone the repository:

```bash
git clone https://github.com/Jayanth-95/NeuroSense.git
```

Navigate into the project directory:

```bash
cd NeuroSense
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the local server in your browser:

```bash
http://localhost:5173
```

# Objective

The primary objective of NeuroSense is to create a smart and accessible platform that supports early cognitive analysis and dementia prediction using AI-driven methodologies and modern web technologies.

The system aims to:
- Improve accessibility to cognitive assessments
- Provide quick and intelligent evaluations
- Assist in early neurological monitoring
- Offer a user-friendly healthcare support solution
